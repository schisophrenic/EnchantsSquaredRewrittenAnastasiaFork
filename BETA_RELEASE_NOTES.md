# ⚠️ BETA TESTING WARNING — NOT PRODUCTION READY

**THIS IS AN EXPERIMENTAL PRE-RELEASE. DO NOT USE ON A LIVE/PRODUCTION SERVER.**

Before installing, make a full backup of your world, player data, inventories, plugin folders, configuration YAML and any custom item definitions. Test on a separate Purpur 26.3 staging server. Expect bugs, incomplete mechanics, unexpected item attributes, enchantment changes, broken smithing upgrades, missing models and possible data loss. **Do not use /reload; stop the server and fully restart.** GitHub Actions checks prove compilation/packaging only; successful runtime behavior has **not** been confirmed.

## What's included
- Native Paper Java enchantment registration and ValhallaMMO tier progression, with per-family tier switches.
- Normal maximum enchantment levels still apply to registry entries; ValhallaMMO may amplify resulting item levels above those maxima.
- Original EnchantsSquared effect IDs preserved where practical; aliases and distinct custom enchantments.
- Configurable Bukkit/ValhallaMMO attribute enchantments (including Graviton), rarities and acquisition chances.
- Magic Protection enchantment-based cap at 85% (other independent systems can contribute additional resistance).
- Optional naturally generated low-quality armor/weapon loot with ValhallaMMO property data and a **soft bridge** to ValhallaEquipment. If Equipment is not loaded, loot generation uses the previous ValhallaMMO-only fallback.

## Install and test
1. Back up everything and use a separate testing server.
2. Use Purpur 26.3 with the compatible ValhallaMMO Premium plugin. Install the matching **ValhallaEquipment BETA** release if you want full equipment property/class/model generation from found loot.
3. Remove old duplicate JARs from `plugins/`. Install this release's EnchantsSquared JAR and the matching Equipment JAR.
4. Back up and review config_native_enchants.yml and ValhallaMMO's enchanting.yml; carefully reconcile existing settings instead of resetting them.
5. Fully restart; watch startup for the **BETA** warning and errors.
6. Try /esnative status, enchantment table levels above vanilla caps, equipment rolled in chests/fishing/mobs, /valeq inspect, smithing upgrades, item models and protections. Verify that enchanting and equipment stats persist after a restart.

**Known limitations:** not all mod enchantments from the comparison audit are implemented; some custom mechanics differ from their Forge equivalents. Custom weapon variants/trinket enchant slots are not generated by the default loot pool. Runtime interactions, protections, drops and upgrades still need full server testing.
